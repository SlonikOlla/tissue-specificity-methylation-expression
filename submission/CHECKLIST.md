# Comparative Biochemistry and Physiology Part D submission checklist

- [ ] Complete author names, order, affiliations, ORCID identifiers and corresponding-author details.
- [ ] Confirm CRediT roles with every author.
- [ ] Replace funding and acknowledgements placeholders.
- [ ] Confirm the declaration of competing interest.
- [ ] Confirm the generative-AI declaration accurately describes author use.
- [ ] Upload 3–5 highlights as a separate editable file (maximum 85 characters each).
- [ ] Upload editable figures and verify caption numbering against the manuscript.
- [ ] Upload supplementary workbooks and a file manifest.
- [ ] Select a repository license and update `CITATION.cff` with URL and DOI.
- [ ] Create a versioned release and archive it with Zenodo or an equivalent DOI service.
- [ ] Verify every accession, DOI, reference, sample count and reported statistic.
- [ ] Confirm that no controlled-access or identifying data are included.
